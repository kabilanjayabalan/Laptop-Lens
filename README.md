## Laptop-Lens Monorepo

This repository contains:

- `frontend`: React + Tailwind CSS SPA
- `backend`: Spring Boot REST API with MongoDB
- `ml`: Python (scikit-learn) service for ML tasks

### Structure

- `frontend/` – React app (no Vite, uses Create React App–style structure)
- `backend/` – Spring Boot project (Maven)
- `ml/` – Python package and scripts for ML
